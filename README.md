# Week 7 Assignment: AI Ethics

This directory contains the submission for the "AI Ethics" assignment.

## Directory Structure

*   **Part 1: Theoretical Understanding**
    *   `Part1_Theoretical_Understanding.md`: Answers to Q1-Q3 and Principles Matching.
*   **Part 2: Case Study Analysis**
    *   `Part2_Case_Study_Analysis.md`: Analysis of Amazon's Hiring Tool and Policing Facial Recognition.
*   **Part 3: Practical Audit**
    *   `Part3_Practical_Audit.ipynb`: Jupyter Notebook auditing the COMPAS dataset for racial bias.
*   **Part 4: Ethical Reflection**
    *   `Part4_Ethical_Reflection.md`: Reflection on personal project ethics.
*   **Bonus Task**
    *   `Bonus_Healthcare_Policy.md`: Policy proposal for ethical AI in healthcare.

## Setup & Installation

1.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

## How to Run

### Practical Audit
Open the Jupyter Notebook:
```bash
jupyter notebook Part3_Practical_Audit.ipynb
```
Run all cells to load the data, calculate fairness metrics, and visualize the bias.
